Terminal

A developer's dark workspace with a CI/CD-style timeline.

darkmonospacedeveloper
Prompt
Create a beautiful portfolio website for a full-stack developer in a dark, terminal-inspired style.

Look and feel: graphite background with a faint grid, JetBrains Mono plus Space Grotesk, blue, amber and green accents. The hero is a terminal window with traffic-light dots, a "$ whoami" prompt and a blinking cursor. Show skills as API endpoints (/backend GET, /cloud POST). Show experience as a CI/CD pipeline timeline with a pulsing "running" node on the current role.

Sections: Hero, Capabilities, Experience, Projects, Contact, plus a small footer (education, certification, languages). Spatial UI

Frosted glass windows floating in 3D, visionOS style.

glass3D tiltdepth
Prompt
Create a beautiful portfolio website in a spatial UI style, like Apple Vision Pro's visionOS.

Look and feel: a soft dusk gradient "environment" with blurred glowing orbs behind everything. Content lives in frosted glass windows (backdrop-filter blur with saturation, thin bright borders, a specular highlight that follows the cursor). Windows tilt in 3D with perspective as the mouse moves, small widgets float forward on the Z axis, each window has a grabber bar underneath, and a vertical icon dock sits on the left edge. Font: Inter.

Sections: Hero, Capabilities, Experience, Projects, Contact, plus a small footer (education, certification, languages).
